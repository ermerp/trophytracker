# Wunschlisten (lokal)

Hier hinein kommen die alten Wunschlisten als Textdateien – so, wie sie sind,
eine Datei je Liste. Nichts umformatieren: Der Import in Stufe 11 (Spezifikation
8.2) soll genau mit diesen Dateien umgehen können, und vorher werden sie hier
gegen `game` und IGDB gemessen, wie beim Trophäen-Abgleich.

Was hilft, wenn es dasteht: die Plattform neben dem Titel (die Suche kann sie
bevorzugen), ein Datum der Liste im Dateinamen (`wunschliste-2021-03.txt`).

**Alles außer dieser README ist über `.gitignore` vom Repository
ausgeschlossen.** Das Repository ist öffentlich; Wunschlisten sind so persönlich
wie die Spielhistorie.
